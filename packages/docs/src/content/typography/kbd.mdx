# Kbd

Kbd renders the native `<kbd>` element for keyboard input while applying Manti
typography, surface, radius, spacing, and elevation tokens.

<Demo name="typography/kbd" center />

Use separate Kbd elements for each key in a combination so assistive technology
and copied text preserve the shortcut structure.
