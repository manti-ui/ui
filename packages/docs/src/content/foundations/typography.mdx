# Typography

Manti UI uses a compact UI-first type scale.

[Text](/typography/text) and [Heading](/typography/heading) put that scale
behind a component API, with a neutral emphasis ladder and semantic color as two
independent axes. The remaining primitives add Manti's token-backed visual
language without giving up native HTML semantics:
[Blockquote](/typography/blockquote), [Code](/typography/code), and
[Kbd](/typography/kbd).

## Size

`--manti-text-xs` through `--manti-text-5xl` provide interface and display
sizes. Pair them with `--manti-leading-none`, `tight`, `snug`, `normal`, or
`relaxed`. `none` (`1`) is for single-line chrome such as a day-cell number or
a segmented-control label, where the box should hug the glyphs.

<TypeScale />

```css
.card-title {
  font-size: var(--manti-text-xl);
  line-height: var(--manti-leading-snug);
}
```

## Weight

Available weights are `regular` (400), `medium` (500), `semibold` (600), and
`bold` (700).

## Tracking

Optical letter-spacing. Large type reads as loose unless it is pulled in, and
small label-ish text reads as cramped unless it is pushed out. The stops are
`--manti-tracking-tighter` (`-0.02em`), `tight` (`-0.01em`), `normal`, `wide`
(`0.02em`), `wider` (`0.04em`), and `widest` (`0.06em`).

Because the values are in `em`, each stop scales with whatever font size it
lands on. Text and Heading step through them automatically as `size` grows.

```css
.hero-title {
  font-size: var(--manti-text-5xl);
  letter-spacing: var(--manti-tracking-tighter);
}
```

## Families

- `--manti-font-sans` — Inter with system fallbacks
- `--manti-font-mono` — system monospace stack
- `--manti-font-display` — the face of [Heading](/typography/heading) and of
  every component title (Card, Dialog, Drawer, Popover, Alert, Toast, Tour,
  FloatingPanel, DataTable and the Steps item title). It defaults to
  `var(--manti-font-sans)`, so headings and body copy share one face until you
  set it.

Inter is not bundled. Load it in the application or override
`--manti-font-sans`.

To give headings and titles their own face, set `--manti-font-display` once:

```css
:root {
  --manti-font-sans: 'Manrope', ui-sans-serif, system-ui, sans-serif;
  --manti-font-display: 'Outfit', ui-sans-serif, system-ui, sans-serif;
}
```

The default resolves on `:root`, so set `--manti-font-display` wherever you
set `--manti-font-sans`. A text face overridden on a narrower scope does not
reach the display face unless you set both there. With Tailwind, the token is
the `font-display` utility.
