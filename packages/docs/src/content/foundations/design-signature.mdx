# Design signature

Manti UI aims to feel **smooth**: quiet surfaces, clear state changes, and
predictable interaction.

## Material

The default interface is cool, near-neutral, and monochrome. Color appears
through semantic variants instead of decoration.

Floating surfaces share one panel treatment:

- translucent surface tint;
- subtle border and top highlight;
- soft shadow;
- blur when the browser and layout support it.

## Main controls

```css
.manti-app {
  --manti-panel-tint: oklch(0.2 0.008 280 / 0.55);
  --manti-panel-border: oklch(1 0 0 / 0.09);
  --manti-panel-highlight: oklch(1 0 0 / 0.08);
  --manti-panel-blur: blur(16px) saturate(160%);
}
```
