# ColorPicker

ColorPicker accepts CSS color strings. Its panel includes a saturation area,
hue and alpha sliders, format tabs, an eyedropper, and a copy field.

<Demo name="color-picker/basic" center />

## Sizes

`size` sets the trigger's height, padding, type, and swatch. The panel keeps its
own canvas: a saturation area and sliders have no rows to rescale.
