# Calendar

Calendar is an inline month surface. Use [DatePicker](/components/date-picker)
when selection should open from a compact field. Values are ISO date strings.

<Demo name="calendar/board" />

## Selection

Use `selectionMode="single"` or `"range"`. Controlled and uncontrolled values
are arrays of ISO dates.

<Demo name="calendar/basic" center />

<Demo name="calendar/range" center />

## Day content

Use `renderDay(day)` for events or other day details. Pair it with `readOnly` for
a display-only calendar.
