# Combobox

Pass options as `{ value, label, disabled? }`. Filtering runs by label while the
Zag.js machine manages focus, keyboard navigation, and selection.

<Demo name="combobox/basic" center />

## Appearance

Use `variant="fill"` for a neutral filled control. `size` uses the shared size
scale: the portalled list follows the control, so a `sm` Combobox filters into
`sm` rows.

<Demo name="combobox/variants" center />

<Demo name="combobox/sizes" center />

## Multiple selection

Set `multiple` to collect several values.

<Demo name="combobox/multiple" center />

## Remote search

To search a server as the user types, control the text with `inputValue` and
`onInputValueChange`, fetch from it, and pass the answer as `items` with
`filter={false}` so it renders as given. Set `loading` while a request is out
and `emptyContent` for an answer with nothing in it; `minChars` keeps the
listbox closed until the query is long enough. Combobox does no fetching,
debouncing or caching itself. A pick stays selected, and a chip keeps its
label, when the next answer replaces `items`.
