# Popover

Pass a React element as `trigger` and the panel body as `children`. The machine
manages placement, focus, and dismissal.

<Demo name="popover/basic" center />

## Placement

`placement` anchors the panel to a side of the trigger, optionally aligned to its
start or end edge. It defaults to `bottom`, and the machine flips the panel when
there is not enough room on the requested side.

<Demo name="popover/placements" center />

## Width

The panel sizes to its content (`width: max-content`) and stops growing at a
default max width of `20rem`. It never grows past the viewport less a
`--manti-space-8` gutter, so it stays on screen on narrow devices. At the
default width, text and long words wrap inside the panel.

For wider content, raise the cap with the `maxWidth` prop, or set a fixed
`width`:

```tsx
<Popover trigger={<Button>Notifications</Button>} maxWidth="28rem">
  <NotificationList />
</Popover>
```

Each prop writes its component token on the content part
(`--manti-popover-max-width`, `--manti-popover-width`), so you can also set the
token in a stylesheet instead:

```css
.notifications-popover {
  --manti-popover-max-width: 28rem;
}
```

Use `contentProps` to pass any other attribute to the content part, such as
`style`, `aria-*` or `data-*`. The machine's own props win, and `className`
and `style` compose with `className`, `width` and `maxWidth`.
