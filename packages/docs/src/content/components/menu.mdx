# Menu

Pass a React element as `trigger`. Action commands use
`{ value, label, icon?, shortcut?, disabled?, tone?, itemProps? }`;
`onSelect` receives the clicked value for pointer, keyboard, and programmatic
activation.

<Demo name="menu/basic" center />

## Composition

Omit `items` and compose the parts instead when a command needs to render more
than a label, an icon, and a shortcut. Both shapes drive the same machine and
the same markup — the shorthand is built out of these parts.

`Menu.Item` wraps its children in the `item-text` slot. Render `Menu.ItemIcon`,
`Menu.ItemText`, `Menu.ItemShortcut`, or `Menu.ItemIndicator` yourself and the
item hands the whole row over to you. Each command also takes its own
`onSelect`, so an action can live next to the item that triggers it.

<Demo name="menu/composed" center />

```tsx
<Menu>
  <Menu.Trigger>
    <Button variant="tertiary">Serve as…</Button>
  </Menu.Trigger>
  <Menu.Content>
    <Menu.Group>
      <Menu.GroupLabel>Toppings</Menu.GroupLabel>
      <Menu.Item value="yogurt" shortcut="⌘1" onSelect={serve}>
        Garlic yogurt
      </Menu.Item>
    </Menu.Group>
    <Menu.Separator />
    <Menu.CheckboxItem
      value="compact"
      checked={compact}
      onCheckedChange={setCompact}
    >
      Compact density
    </Menu.CheckboxItem>
  </Menu.Content>
</Menu>
```

The parts are `Menu.Trigger`, `Menu.Content`, `Menu.Item`,
`Menu.CheckboxItem`, `Menu.RadioItem`, `Menu.Group`, `Menu.GroupLabel`,
`Menu.Separator`, `Menu.ItemIcon`, `Menu.ItemText`, `Menu.ItemShortcut`, and
`Menu.ItemIndicator`. [ContextMenu](/components/context-menu) exposes the same
set below its trigger.

## Groups

Add `{ type: 'group', label, items }` or `{ type: 'separator' }` entries.

<Demo name="menu/grouped" center />

## Checkbox and radio items

Set `type="checkbox"` or `type="radio"` together with `checked` and
`onCheckedChange`. Manti renders `menuitemcheckbox` or `menuitemradio` and an
`item-indicator` part. Use `tone="danger"` for destructive commands.

`itemProps` customizes one item; `getItemProps` customizes items centrally.
Handlers are chained with the machine, while machine-owned roles and keyboard
behavior remain authoritative. Menu items do not support nested interactive
controls.

## Placement

`bottom-center` aliases the centered `bottom` placement. Use `-start` or `-end`
for edge alignment.
