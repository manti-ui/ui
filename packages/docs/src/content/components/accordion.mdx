# Accordion

Pass `items` as `{ value, title, content }`. The Zag.js machine manages focus,
keyboard navigation, and open panels.

<Demo name="accordion/basic" />

## Multiple panels

Set `multiple` to keep several panels open. Use `defaultValue` for the initial
uncontrolled state.
