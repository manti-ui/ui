# Manti UI

Manti UI is a React component library built on framework-agnostic tokens, CSS,
and behavior.

## Start

```tsx
import '@manti-ui/styles/index.css';
import { Button } from '@manti-ui/react';

export function Example() {
  return <Button variant="primary">Save</Button>;
}
```

Use the toolbar to switch themes. Component stories cover variants, states,
sizes, and interactions.

## Packages

- `@manti-ui/tokens` — typed token contract
- `@manti-ui/styles` — shared CSS
- `@manti-ui/folds` — Zag.js and Manti-authored behavior
- `@manti-ui/react` — React renderers and hooks

The full guides and component API reference live at
[manti.design](https://manti.design).
